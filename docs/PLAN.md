# Regal Park CRM — build spec (source of truth for every brief)

White-labelled real-estate CRM for **Sterlitee Developers — Sterlitee Regal Park** (Neotown, Electronic City,
Bengaluru, Karnataka). Modelled on the Perfex "Real Estate Management" module (admin demo explored 2026-11-22).
Keep it simple: CRUD + a few workflows. No DB — JSON file. TypeScript everywhere.
OUT OF SCOPE: Zoho, Xero, Support/tickets, map widget (use "Open in Google Maps" link), real email, uploads.

## 1. Stack (fixed)
- Root `G:\equinox-22`. Node 22, npm. Single package.
- Client: Vite 5 + React 18 + TypeScript + react-router-dom 6 + recharts + lucide-react. Plain CSS (`client/theme.css`), no UI kit.
- Server: Express 4 + TypeScript run with `tsx`. Port **4000**. Vite dev port **5173**, proxy `/api` → 4000.
- Data: `data/seed.json` (committed, generated by `scripts/seed.ts`), `data/db.json` (runtime copy, gitignored; created from seed on start if missing).
- Tests: vitest (+ supertest for API, jsdom + @testing-library/react for UI). Tests live in `tests/`.
- Scripts: `dev` (concurrently server+client), `server`, `client`, `seed` (tsx scripts/seed.ts), `typecheck` (tsc --noEmit -p .), `test` (vitest run), `build` (vite build).
- **Gate:** `npm run typecheck && npm test && npm run build`.
- Paths: `shared/` (types, permissions, format — imported by both sides via relative imports), `server/`, `client/`, `scripts/`, `tests/`, `data/`.

## 3. Data model (`shared/types.ts` — exact names)
```ts

export interface Base { id: string; createdAt: string; createdBy?: string }
export interface User extends Base { name: string; email: string; password: string; role: Role; phone?: string; active: boolean; linkedId?: string } // linkedId → agents/brokers/owners/clients/staff record
export interface Owner extends Base { code: string; name: string; email: string; phone: string; city: string; state: string; address?: string; pan?: string; active: boolean }
export interface Staff extends Base { code: string; name: string; email: string; phone: string; designation: string; approvalManager: boolean; requireApproval: boolean; isPublic: boolean; active: boolean; lastLogin?: string }
export interface Agent extends Base { code: string; name: string; email: string; phone: string; city: string; reraAgentNo?: string; planId?: string; verified: boolean; isPublic: boolean; active: boolean }
export interface Broker extends Base { code: string; name: string; email: string; phone: string; city: string; reraAgentNo?: string; planId?: string; active: boolean }
export interface Client extends Base { code: string; name: string; email: string; phone: string; city: string; type: 'Buyer'|'Tenant'|'Investor'; company?: string }
export type PropertyStatus = 'Pending'|'New'|'Active'|'Pending Sale'|'Closed Sale'|'Sold'|'Rented'|'Temp off Market'|'Withdrawn'|'Cancelled'|'Backup'|'Expired';
export interface Property extends Base { code: string; name: string; project?: string; listingType: 'Housing'|'Business'|'Agriculture'|'Government';
  style: 'Villa'|'Apartment'|'Plot'|'Duplex'|'Penthouse'|'Commercial'|'Office'|'Row House'; status: PropertyStatus; transactionType: 'Sale'|'Rent';
  price: number; rentalPrice?: number; rentalType?: 'Month(s)'|'Year(s)'; reservationAmount?: number; maintenanceFee?: number;
  beds: number; baths: number; areaSqft: number; plotSqft?: number; floors?: number; facing?: 'East'|'West'|'North'|'South'|'North-East'|'North-West'|'South-East'|'South-West';
  furnished: 'Unfurnished'|'Semi-Furnished'|'Fully Furnished'; condition: 'Completed'|'Under Construction'|'Pre Construction'|'Under Renovation'; newConstruction: boolean;
  yearBuilt?: number; possessionDate?: string; address: string; city: string; state: string; zip: string; lat?: number; lng?: number;
  amenities: string[]; ownerId?: string; agentId?: string; brokerId?: string; approval: 'pending'|'approved'|'rejected'; rejectReason?: string;
  listingPrivacy: 'public'|'internal'; description?: string; expenses: {label: string; amount: number}[]; rooms: {type: string; level: string; widthFt: number; lengthFt: number}[] }
export type LeadStatus = 'New'|'Contacted'|'Site Visit Scheduled'|'Site Visit Done'|'Negotiation'|'Booked'|'Lost';
export interface Lead extends Base { name: string; phone: string; email?: string; source: 'Website'|'99acres'|'MagicBricks'|'Housing.com'|'Walk-in'|'Referral'|'Channel Partner'|'Facebook Ads'|'Google Ads';
  interest: string; budget?: number; status: LeadStatus; assignedTo?: string /* user id */; siteVisitDate?: string; propertyId?: string; notes?: string }
export type RequestStatus = 'Draft'|'Submitted'|'Sent'|'Waiting for approval'|'Approved'|'Cancelled'|'Complete'|'Expired';
export interface PropertyRequest extends Base { number: string; kind: 'buy'|'rent'; propertyId: string; clientId: string; propertyPrice: number; contractAmount: number;
  termMonths: number; startDate: string /* expected buy date OR preferred lease start */; endDate?: string; status: RequestStatus; inspect: boolean; inspectionDate?: string;
  clientNote?: string; adminNote?: string; contractId?: string; invoiceId?: string }
export interface Tenant extends Base { referenceNo: string; clientId: string; propertyId: string; requestId: string; leaseStart: string; leaseEnd: string; monthlyRent: number; deposit: number; status: 'Active'|'Notice Period'|'Ended' }
export interface Contract extends Base { number: string; requestId: string; kind: 'buy'|'rent'; clientId: string; propertyId: string; amount: number; signed: boolean; signedAt?: string }
export interface Payment { date: string; amount: number; mode: 'UPI'|'NEFT'|'RTGS'|'Cheque'|'Cash' ; ref?: string }
export interface Invoice extends Base { number: string; requestId?: string; kind: 'buy'|'rent'; clientId: string; propertyId: string; amount: number; dueDate: string; payments: Payment[]; status: 'Unpaid'|'Partially Paid'|'Paid'|'Overdue'|'Cancelled' }
export interface Plan extends Base { name: string; monthlyListings: number; rate: number; paymentType: 'Monthly'|'Yearly'; description?: string }
export interface Settings { companyName: string; productName: string; projectName: string; tagline: string; rera: string; phone: string; email: string; address: string;
  currency: 'INR'; showBrokerPortal: boolean; requirePropertyApproval: boolean;
  prefixes: { property: string; owner: string; agent: string; broker: string; staff: string; client: string; buy: string; rent: string; invoice: string; contract: string; tenant: string };
  nextNumbers: Record<keyof Settings['prefixes'], number> }
export type Action = 'view'|'create'|'edit'|'delete';
export type Module = 'dashboard'|'properties'|'approvals'|'leads'|'owners'|'staff'|'agents'|'brokers'|'clients'|'buyRequests'|'rentRequests'|'tenants'|'invoices'|'contracts'|'reports'|'settings';
export type PermissionMatrix = Record<Role, Partial<Record<Module, Action[]>>>;
export interface DB { users: User[]; owners: Owner[]; staff: Staff[]; agents: Agent[]; brokers: Broker[]; clients: Client[]; properties: Property[]; leads: Lead[];
  requests: PropertyRequest[]; tenants: Tenant[]; contracts: Contract[]; invoices: Invoice[]; plans: Plan[]; settings: Settings; permissions: PermissionMatrix }
```
Collection → module map: owners→owners, staff→staff, agents→agents, brokers→brokers, clients→clients, properties→properties, leads→leads,
requests→buyRequests|rentRequests (by `kind`), tenants→tenants, contracts→contracts, invoices→invoices, plans→settings, users→settings.

## 5. REST API (all JSON, all under `/api`, auth header `Authorization: Bearer <token>`)
- `POST /auth/login {email,password}` → `{token,user}` (user without password). 401 bad creds / inactive. Token = random id kept in an in-memory Map. `GET /auth/me`. `POST /auth/logout`.
- Generic CRUD for collections `owners staff agents brokers clients properties leads requests tenants contracts invoices plans users`:
  `GET /:col` (scoped list, `?kind=buy|rent` for requests), `GET /:col/:id`, `POST /:col`, `PUT /:col/:id` (merge), `DELETE /:col/:id`.
  Unknown collection 404; missing id 404; no permission 403; missing required field 400 `{error, field}`. Required: name for people/plans; name, price≥0, transactionType for properties; name+phone for leads (phone = 10-digit Indian mobile, optional +91); propertyId+clientId+kind for requests. Codes/numbers auto-assigned on create from prefixes+nextNumbers (e.g. `SRP-0041`, `BR-0016`), id = random short string. createdAt/createdBy set by server. Passwords never returned.
  Non-admin creating a property → approval 'pending' when settings.requirePropertyApproval.
- `POST /properties/:id/approve`, `POST /properties/:id/reject {reason}` (approvals module, edit).
- `POST /requests/:id/status {status}` (valid RequestStatus only). Approving a **rent** request creates a Tenant (once) and sets property status 'Rented'; completing a **buy** request sets property 'Sold'.
- `POST /requests/:id/contract` → creates Contract (once, returns existing if present), links contractId. `POST /contracts/:id/sign`.
- `POST /requests/:id/invoice` → creates Invoice (buy: reservationAmount or 10% of contractAmount; rent: monthlyRent = contractAmount/termMonths rounded), links invoiceId.
- `POST /invoices/:id/payments {date,amount,mode,ref}` → amount>0 and ≤ balance else 400; status recomputed (Paid / Partially Paid).
- `GET /dashboard` → scoped aggregates: saleIncome, rentalIncome (sum of paid invoice payments by kind), forSale, sold, selling (Pending Sale), forLease, rented, available, propertyByStatus[], buyByStatus[], rentByStatus[], requestsByListingType[], topCities[], leadsByStatus[], leadsBySource[], recentLeads[5].
- `GET /reports/:type` type ∈ rent-paid, vacant-rental, rental-units, delinquent-tenants, leases-ending (≤90 days), vacant-sale, sold-units, lead-funnel. Returns `{columns:string[], rows:any[][]}`.
- `GET /settings`, `PUT /settings`, `GET /permissions`, `PUT /permissions` (settings module). `POST /admin/reset` (admin) → re-copy seed to db.
- Persistence: every write saves db.json synchronously (write temp + rename).

## 8. Integration notes (as built in Phase 1 — read before writing a page)
Client components (`client/components/`):
- `ui.tsx`: Button (variant primary|gold|ghost|danger|success, size="sm"), Badge, StatusBadge (colour map for all statuses), Card, StatCard, Tabs, ConfirmDialog, PageHeader, Empty, ToastProvider, `useToast()` → `toast(msg, 'success'|'error'|'info')`, SearchCtx (topbar search; DataTable already consumes it).
- `DataTable.tsx` default export, props `{columns, rows, actions?, search?, exportName?, emptyMessage?}`; Column `{key, label, render?, sortValue?, width?}` (search/sort/CSV use sortValue or row[key]).
- `FormModal.tsx` default export, props `{title, fields, initial?, submitLabel?, onSubmit(values): Promise, onClose}`; closes itself when onSubmit resolves, shows thrown Error inline; numbers converted; exported types Field, FieldOption, FormValues. Field types: text, number, email, tel, date, select, multiselect, textarea, checkbox.
- `api.ts`: `api.get/post/put/del<T>(path, body?)` (path WITHOUT /api prefix, e.g. `api.get('/properties')`), throws Error(message) with `.status`/`.field`.
- `auth.tsx`: `useAuth()` → `{user, loading, permissions, settings, login, logout, can(module, action)}`, `BRANDING`.
- theme.css classes available: .stat-grid, .grid-2, .filters, .kanban, .kv, .hero, .thumb, plus cards/tables/badges/buttons/modal/tabs/form grid.
- Shared: `../../shared/format` (formatINR, formatShort, formatDate, isIndianMobile), `../../shared/types` (types + status/source arrays, ROLE_LABELS).
Server behaviour:
- Out-of-scope record → 403, missing → 404. Non-admin roles may get 403 on lookups (e.g. agent/client loading /owners, /agents, /brokers): pages MUST tolerate a 403 on secondary lookups (show code/"—" instead of crashing).
- GET /plans, /settings, /permissions: any logged-in user. Dashboard extra fields: leadsThisMonth, siteVisitsScheduled; aggregate arrays are `[{name, value}]`.
- Client creating a request: clientId forced to own. Agent/broker/owner-created property or lead is force-linked to them. Non-admin property create → approval pending, status Pending (admin approve → Active).
- Request defaults: status Submitted; rent termMonths 11. Closed requests (Cancelled/Complete/Expired) cannot change status (400). POST /requests/:id/invoice creates a NEW invoice each call (relinks invoiceId); contract is created once.
- Optional numbers sent as '' are stored as undefined. Seed phones look like "+91 98450 12345". Rental properties: price = rentalPrice = monthly rent. Buy requests termMonths 0.
