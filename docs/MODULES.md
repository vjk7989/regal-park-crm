# Module catalogue — full Perfex admin (inventory of 420 pages, 2026-11-22)

Source: crawl of every sidebar page at perfexmodules.gtssolution.site/admin (table columns + status options). Each module below becomes a `ModuleDef` (see PLAN §10). Page kinds: **D** dashboard, **T** table (entity CRUD), **R** report, **S** settings (module settings form + lookup tabs), **C** calendar. Status lists are the option values to use. Mock data must suit **Sterlitee Developers, an Indian (Bengaluru) real-estate developer** — use the "flavour" line.

Excluded: Zoho, Xero, Support (user); Quickbooks, Sage Accounting, Freshbooks (same sync-only integrations); Setup (our Settings). Real Estate already built. Core "Leads" = existing Leads page.
